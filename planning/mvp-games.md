# MVP: 20 games, Pre-K to Grade 2

## Math (8)
1. Count objects 1 to 10 (Pre-K)
2. Shape matching (Pre-K)
3. Count to 20 (Kindergarten)
4. Add with objects (Kindergarten)
5. Addition within 20 (Grade 1). Built as "Addition Garden" and redesigned on 2026-11-12 as a hands-on game (Seed Stall,
   Stepping Stones, garden rewards). Live. A number line version can come later (`math.addition.within-20`).
6. Subtraction basics (Grade 1)
7. Add and subtract to 100 (Grade 2)
8. Skip counting (Grade 2)

## Language (8)
9. Letter tap (Pre-K)
10. Drag letter to object (Pre-K)
11. Phonics: sound to letter (Kindergarten)
12. Sight word balloons (Kindergarten)
13. Word building (Grade 1). Built as "Letter Workshop" on 2026-11-13 (slot-build mechanic, kit v0.4.0, word wall
    reward). Page at `/language-games/word-building-for-grade-1/` (`language.phonics.word-building`).
14. Sentence completion (Grade 1)
15. Spelling, 4 to 6 letters (Grade 2)
16. Noun and verb sort (Grade 2)

## Logic and memory (4)
17. Memory flip cards (Pre-K to Kindergarten). Built as "Quilt Picnic" on 2026-11-13 (pair-match mechanic, kit v0.5.0,
    quilt reward). Page at `/logic-games/memory-match-for-preschool/` (`logic-memory.memory.matching-pairs`). Website side is
    done; the game build and poster arrive with `npm run sync-game -- ../memory-match-prek`.
18. Color pattern repeat (Kindergarten)
19. Odd one out (Grade 1)
20. Pattern completion (Grade 2)

Build order: Addition for Grade 1 (number 5) first, as the engine test and the template proving game. Done:
live at `/math-games/addition-for-grade-1/`.
